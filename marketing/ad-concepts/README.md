# DreamBot Ad Concepts — snapshot 2026-07-27

Historical/reference snapshot of the Instagram ad-concept exploration. Each `.html`
file is a **self-contained** sheet (all art embedded as data URIs) — open any of them
directly in a browser, no server or assets needed. Start with `0-START-HERE.html`.

These are **layout + copy mockups** (directions to react to), not final exportable ad
files. The lore, characters, and voice rules behind them are canonical in
[`../../MASCOT_LORE.md`](../../MASCOT_LORE.md).

## Brand recap (baked into every sheet)

Deep-dark dreamy ground · purple→pink→teal gradient · rounded display type · glowing
lavender/gradient caption pills · sparkles. Three tenets: 🌙 dreams nightly · 🎨 every AI
model · 🔭 a feed to explore. Tagline: **Dream it. Make it.** No em dashes; the taco is
happy by canon.

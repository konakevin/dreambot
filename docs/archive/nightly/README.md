# Archived nightly docs

Plans, investigations, ledgers and runbooks from the nightly engine's history (April - October 2026), moved here on
2026-10-02 when `NIGHTLY_RULE_BOOK.md` became the one official nightly doc. Each keeps its original file name, so code
comments and migration headers that cite a name by itself still find it here.

Read them for the history behind a rule (the measurements, the rejected hypotheses, Kevin's decisions), never as the
current state. Anything still true lives in the rule book; if you find a still-true rule here that the rule book
lacks, add it there.

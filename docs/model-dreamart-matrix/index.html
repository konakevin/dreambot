DreamBot — Dream Art model × style matrix

Historical study, July 2026 · 264 renders · rows = cast (me / my +1 / both) · columns = model · green = kept in the style's DreamSmart set (style + resemblance) · red = excluded · click a render to enlarge.

Key findings

Study: every DreamBot model × every embodied Dream Art style × three cast configs (me / my +1 / both), one fixed scene per style. 264 renders.

Bar: a pass requires BOTH the style (anime looks anime, clay looks clay) AND a recognizable look-alike of the cast (bearded man / dark-haired woman), not just the style.

  • ALL MODELS PASS anime, claymation — the character carries the likeness on every model.
  • CURATED animation, fairytale, storybook, pixels — the style's prior overrides the cast on some models (young-boy / clean-shaven-prince / smooth-not-pixel), so only the resembling models are kept.
  • LOOSE LIKENESS handcrafted (yarn dolls), kawaii (chibi) — the aesthetic erases adult-male features; passes are the best-quality, but resemblance is loose.

Outcome: each style stays a Dream Art style; its smart_dream_models is set to its passing models (the DreamSmart checkbox curates to those). Every medium keeps a non-empty set so the checkbox is always visible.

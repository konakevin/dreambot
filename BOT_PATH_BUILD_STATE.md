# Bot Path Build State — master tracker

Living state board for the **bot-path expansion run** (Kevin, 2026-08-14): build EVERY new
path in `EXPAND_BOT_BLINDSPOTS.md` (the master spec) via the 25-seed QA loop, one at a time,
bespoke, no rushing. Full specs per path live in `EXPAND_BOT_BLINDSPOTS.md §<id>`; this file
tracks **state + grade**.

## The loop (per path)
1. **Research** the bot — re-read its `BOT_SCENE_QUALITY_PLAYBOOK.md` section + map its module.
2. **Build** it bespoke at **MVP-25** (recipes + archetype + template + path file + pools + wiring).
3. **Shadow-post** a test batch — `shadowPaths[]` + `iter-bot --post` (SHADOW, admin-only; the
   standard from [[feedback_always_post_test_renders_not_tmp]]). Kevin can review in-app anytime.
4. **QA (view)** the renders for adherence to the bot's vibe + the new path's intent — I grade.
5. **Tweak if needed** (reseed the 25 pool / tweak template / prefix / pools) → view again.
6. **Up to 3 rounds or until ≥4.5/5.** If it can't reach 4.5/5 in 3 rounds, stop at 3 and mark
   `⚠ future-iter` (revisit later to lift it).
7. **Leave at MVP-25** — everything is prepared for ONE big production seed at the very end.

**Grading is mine** (Kevin's explicit delegation, 2026-08-14 — "you've made the right choices,
I trust you"). My grades skew harsh, so 4.5/5 = genuinely strong. Everything shadow-posted so
Kevin can double-check in the app.
